# Final presentation sources

30 scenes, 98 authored states, 2700 seconds of speaking/animation timing.
English presentation; Turkish narration. This is the owner's final revised package.

Build the self-contained HTML with Python's standard library:

```sh
python3 presentation/revised/tools/build.py
```

The output is `presentation/revised/START_PRESENTATION.html`. The current published
copy is `publication/2026-11-04/START_PRESENTATION.html`. When changing sources,
update publication copies and their artifact hashes together.

`docs/QA.md` records the original rendering checks and their environment limits.
This integration does not run new model experiments or change scientific results.
